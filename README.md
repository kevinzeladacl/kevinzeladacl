#### 💼 About Me

Software engineer with **10+ years building web, mobile and AI products end to end** — from architecture and code to production on AWS and Azure. I've worked as **Technical Lead, Lead Developer and CTO**, and co-founded two software companies (**AppFactory** and **KZ Team**).

Since 2023 I've focused on **applied AI**: integrating LLMs into production (OpenAI, Anthropic Claude, Azure OpenAI, Gemini), building AI agents and agentic infrastructure, and designing the public API and official **Python SDK** of an AI platform (CodeGPT). I use AI-assisted development (Claude Code, OpenAI Codex) every day.

I'm also co-founder of **ProinChile**, a community of programmers and IT professionals, and I enjoy teaching workshops and sharing knowledge.
